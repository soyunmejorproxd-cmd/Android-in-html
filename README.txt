ANDROID IN HTML — MATERIAL 3 FINAL

Esta versión usa el bundle oficial @material/web/all.js de Material Web de Google, v2.5.0, mediante el import map oficial de esm.run.

Importante: abre el proyecto mediante HTTP, por ejemplo:
  python -m http.server 9000

Luego entra en:
  http://localhost:9000/

No abras index.html mediante file:// porque los módulos ES y fetch del catálogo necesitan un origen HTTP.
